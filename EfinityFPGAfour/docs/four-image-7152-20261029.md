# Image7 / Image1 / Image5 / Image2 四镜像固化

本包使用 Efinity **Selectable Flash Image / internal** 模式，面向 Ti60F225 和现有 8 MiB 配置 Flash。上电默认 image7。SD 中的 MODEL7.BIN 与此前相同，236448 字节，无需换权重。

四槽顺序及起始字节地址：slot0=image7@0x000000，slot1=image1@0x280000，slot2=image5@0x500000，slot3=image2@0x680000。不要再用旧三镜像文件替代本包，也不要以 external 模式二次合并。

## 手动烧录与切换

1. 在 SPI Programmer 中直接选择 `E:\Efinity_Project\Hex\Hex7152_INTERNAL_20261029.hex`，从地址0烧录，并执行读回校验。由用户操作板卡，本次软件构建没有执行下载或烧录。
2. 重新上电，默认进入 image7。长按 SW1 打开菜单，SW2/SW3 或旋钮移动到 BOOT IMAGE，短按 SW1 循环选择 IMAGE7、IMAGE1、IMAGE5、IMAGE2。
3. 移到 LOAD IMAGE，短按 SW1，等待重载。仅改变 BOOT IMAGE 不会自动切换；选择当前程序时显示 HERE。WAIT 表示等待当前任务结束，LOAD 表示已提交重载，ERROR 表示未能完成切换。
4. image2 的 BOOT IMAGE / LOAD IMAGE 在最后两项。拍照或SD读写中发起切换时，会阻止新任务，并等待已接受任务完成，避免中断 FAT/目录提交。长时间 UART 导出期间请先等导出结束；若等待超时显示 ERROR，可在任务结束后再执行 LOAD。

## 本轮修改

- image2 的 **Canny H=25、L=8**，与 image1 一致；RGB 白平衡增益 **R=496、G=416、B=313**；Gamma 默认开启，强度 **255**。这些是菜单十进制显示值。保留 image2 上电彩色实时显示，阈值复位、白平衡复位也回到这些新值。
- image2 保留此前用户已确认的完整流畅视频版本，SAVE SD 的 WAIT / OK / ERROR 来源于实际采集、SD写入及文件提交状态。拍照成功保持实时画面，只有主动选择 GALLERY 才进入相册。
- 四份程序均增加第四个目标 IMAGE2。image1 仅修改镜像选择范围和名称，不加入额外编号标记；image5/image7 保持已确认的稳定视频、原有 H23/L11 与原有ISP设置。image7 保留11点模型、骨架显示及 USB PTS 默认关闭的发送开关。
- 配置控制和菜单均为私有副本，原 image1/5/7、已确认 image2 拍照版及 image6 源码未改，旧 BIT/HEX 全部保留。工程位于 `images/image1_four_boot`、`image2_four_boot`、`image5_four_boot`、`image7_four_boot`。

## 构建与验证

使用已提交的四个私有工程直接构建，不必重新运行创建副本的开发辅助脚本。

```powershell
powershell -ExecutionPolicy Bypass -File tools/build-four-image.ps1 -Image 1
powershell -ExecutionPolicy Bypass -File tools/build-four-image.ps1 -Image 2
powershell -ExecutionPolicy Bypass -File tools/build-four-image.ps1 -Image 5
powershell -ExecutionPolicy Bypass -File tools/build-four-image.ps1 -Image 7
powershell -ExecutionPolicy Bypass -File tools/test-four-image.ps1
```

发布脚本仅接受通过完整 setup/hold、CDC、引脚与资源检查的文件，同时验证源文件指纹。测试覆盖全部12个跨镜像方向、实际按键菜单、四个名称和切换状态、image2默认值与复位、三拍视频信号对齐、真实SD4/FAT32保存与失败重试、实时DDR画面调度、手动相册、以及保存过程中执行 LOAD 时安全排空。

合并后逐槽检查 internal 重载使能及相同地址表，确认合并只修改允许的选项位、四份配置载荷保持一致、镜像之间不重叠且总量不超过8 MiB。详细证据在 `reports` 和 `manifest.json`。本包的四镜像实板切换与实际显示效果仍需烧录后确认，离线时序与仿真不能代替实板验收。
