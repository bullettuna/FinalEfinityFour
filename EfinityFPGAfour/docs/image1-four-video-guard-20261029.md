# Image1 四镜像版花屏：加强时序裕量的对照候选

用户反馈：烧录 `Hex7152_INTERNAL_20261029.hex` 后，通过菜单切换到 image1 出现花屏。随后用户按要求单独 JTAG 下载同款 `Image1_FOUR_BOOT_20261029.bit`，确认也会花屏。因此故障在独立下载时同样能够复现，当前重点检查 image1 位流自身的视频链路与布局。不能仅凭此反馈断定唯一根因是时序，也不能把原 STA 通过当成实板稳定。

用户同时确认：花屏时发送 `Z`，四色测试图完整稳定。这支持优先检查摄像头接收、DDR帧数据和图像处理路径，仍不能单凭色块排除所有与真实图像数据相关的显示时序问题。

## 已核对的差异

原四镜像 image1 的 BIT SHA256 为 `6fcbdf421f88b2bdd5420cfa062695f53c0df4283f5a79f8a52dcc7061a54680`。其视频算法、帧缓存调度、菜单以外控制、引脚、PLL 和 DPHY tap，与此前正常的 image1 保持一致，但菜单改为四槽后重新布局布线，配置数据已不同。

原四镜像报告中，CSI 输入保持 slack 为 +0.021 ns，像素域建立 slack 为 +0.071 ns；旧三镜像正常版本分别为 +0.037 ns、+0.073 ns。这些是工具模型下的余量，不是板上实测窗口，数值接近不能证明它们是花屏唯一原因。仍需区分布局采样问题、暖重载初始化和烧录读回等因素。

## 本候选修改范围

- 隔离工程 `images/image1_four_video_guard`，复用原四镜像 image1 的同一份已综合网表；视频和菜单 RTL、引脚、PLL、DPHY tap 均逐字节一致，不添加功能硬件、不改时钟频率和分辨率。
- 为布局布线增加 CSI setup 0.8 ns、hold 0.6 ns，以及像素域 setup 0.25 ns 的额外工程裕量。不是实测抖动值，也不通过改慢时钟或放宽约束来消除报告违例。
- 所有 setup/hold 关系、实际关键路径所用不确定度和 CDC 仍须通过；失败的布局不得发布为候选。
- 重新合并时仅替换 image1；image7、image5、image2 使用上次交付的原始文件。合并后逐字节确认这三个槽与旧合并 HEX 相同。
- 旧 BIT/HEX 和原四镜像工程均保留。SD 的 MODEL7.BIN 不用更换。

## 实板对照步骤

1. 建议先临时 JTAG 下载 `E:\Efinity_Project\Hex\Image1_VIDEO_GUARD_20261029.bit`，观察实时图像约一分钟，并验证菜单能正常打开。此步不写配置 Flash，可先判断 image1 自身候选是否正常。
2. 对照稳定后，再用 SPI Programmer 从地址0烧录 `E:\Efinity_Project\Hex\Hex7152_IMAGE1_GUARD_20261029.hex`，执行读回校验。无需二次合并，也不要覆盖旧文件。
3. 上电默认 image7。长按 SW1 打开窗口，BOOT IMAGE 选择 IMAGE1，再在 LOAD IMAGE 短按 SW1；继续验证 7→1、5→1、2→1。image2 要等拍照或SD操作结束。
4. 如果独立 JTAG 正常而菜单切换仍异常，应继续查暖重载初始化和 Flash 读取，不把新的时序报告当成故障已经解决的证据。
5. 若仍花屏，用控制串口 115200、8N1、不加换行发送单个 `Z`；完整稳定的四色图支持继续查相机/帧缓存路径，四色也异常则需查显示输出。再次发送 Z 退出。反馈独立下载和菜单切换各自表现即可，无需更改硬件接线。

本次只生成软件、候选位流和合并文件，没有操作用户的下载器、串口或 SD 卡。所有离线证据位于交付包 `reports`；实板是否恢复仍待用户验证。

## 本次离线结果

采用 TIMING_2 / seed21，全部28项 setup/hold 关系非负、CDC无同步器警告。CSI setup/hold 的额外0.8/0.6ns要求实际应用后，剩余slack分别为 +1.144/+0.002ns；像素域额外0.25ns setup要求实际应用后，剩余setup slack为+0.057ns，hold为+0.030ns。CSI路径实际报告的不确定度为setup 0.910ns、hold 0.670ns，像素setup为0.360ns。这些数值已经扣除额外要求，不能与未增加裕量的旧报告直接比较。

DDR core_clk→twd_clk setup slack为+0.007ns；全报告最小值为CSI hold的+0.002ns。离线通过仍不等于所有实板条件已经覆盖，必须进行本候选的一分钟独立下载对照。CONGESTION_1 / seed7候选存在像素setup -0.539ns及core_clk→twd_clk setup -0.013ns违例，未采用。

资源保持52,968 XLR、197 RAM10、12 DSP；综合网表SHA256保持 `19d02c9ff03ac5473e49610b15eaaffcc817e09ab9c0891f6fefc6474671d171`。候选BIT SHA256为 `f53488b541820a15247a3c40c0ac78132db365642dd7e1190a5030d65792c62f`。
