## 显示和处理

上电直接显示黑底白边的二值 Canny 视频，每个有效像素只能为 0 或 255。
处理顺序：

1. 沿用 image1 灰度转换。
2. 新增 Canny 前置 3×3 中值滤波，使用原有 `median3x3_kernel` 精确九点中值，降低椒盐噪点。
3. 沿用 `canny_edge` 的 3×3 Gaussian、梯度、非极大值抑制、双阈值、局部八邻域连接。
4. 两级 3×3 边缘清理：中心必须原本就是边缘，且至少有两个八邻域边缘邻居。去掉孤立点和较短开放碎线，保留连续的一像素线。
5. 将流水线启动边缘的顶部 12 行、左右各 2 列及底部 2 行置黑。没有裁剪 DE、减少行宽或改变 HDMI 输出分辨率。

**移植细节：** image1 当前的梯度实现按最强 RGB 通道计算，`per_img_gray` 本身不参与梯度选择。
因此 image5 将中值处理后的灰度值同时连接到 Canny 的 R/G/B 输入，三个通道数值相同，得到灰度梯度。
不能把这三个输入绑零，否则会丢失全部图像梯度。

这是自然边缘预处理，不做人体识别、人体轮廓补画、轮廓填充或模板匹配。
小噪点和开放短碎边会减少；桌沿、布褶皱、阴影边界、衣服大纹理等较长轮廓仍可能保留，
小闭合圈也不保证被清除。它不能仅凭局部边缘判断一个物体是否为人体。
建议先用均匀浅色背景、人体与背景有亮度差的衣服验证，再换实际背景。

## 串口测试

沿用 **115200、8 数据位、无校验、1 停止位**。单字符命令分别发送，使用下列大写字母。

- `V`：回复 `5`，确认当前运行 image5。
- `E`：回复 `2`，显示二值 Canny（上电默认）。
- `G`：回复 `1`，显示灰度，受中值开关 M 控制。
- `C`：回复 `0`，显示原彩色画面，便于确认摄像头正常。
- `T`：按彩色 → 灰度 → Canny → 彩色循环。
- `M`：切换 Canny 前置中值滤波；回复 `1` 开启、`0` 关闭，上电默认开启。
- `D`：切换两级边缘碎点清理；回复 `1` 开启、`0` 关闭，上电默认开启。image5 的 D 不表示形状识别。
- `H60` 加回车：设置高阈值 60，回复 `K`。
- `L30` 加回车：设置低阈值 30，回复 `K`；低阈值最大为高阈值。
- `+` / `-`：高阈值加一 / 减一；低阈值超过新高阈值时被限制。
- `R`：回复 `R`，恢复 image5 默认高/低阈值 **60/30**，不重置 M/D。
- `F`：回复 `1` 表示冻结、`0` 表示实时。
- `Z`：回复 `1` 表示 HDMI 诊断画面、`0` 表示摄像头。
- `?`：查询当前请求的模式 0/1/2。

推荐操作：下载后发 `V`，应回复 `5`；发 `E` 后直接观察轮廓。
噪点多时先确认 M/D 都为 1，再尝试 `H90` 回车、`L45` 回车。
边缘太少或断裂时尝试 `H40` 回车、`L20` 回车；`R` 可恢复 60/30。
以上数值是调试起点，需要根据实际光照和衣服调整，不能承诺所有场景固定阈值有效。
阈值在完整输入帧边界更新。

M/D 关闭时仍走相同窗口中心和相同延迟；M/D 请求在消隐期应用，避免切换后像素、行和同步信号错位。
没有自动 ADC 调阈值或周期性 ADC/POSE 输出。未加入 image3 背景差分、白背景分割或 image4 骨架。
O、U、N、拍照/相册等已裁掉的功能不能在 image5 使用。
