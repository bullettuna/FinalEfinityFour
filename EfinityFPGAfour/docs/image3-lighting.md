用户确认使用普通静态彩色背景，灯光基本固定，不使用变色 RGB 灯或播放内容的屏幕。
本版在原上半身匹配和 2 Hz POSE 报告基础上，增加基于 Bayer 颜色比例的阴影判断与整体曝光补偿。
不要求白布；仍需固定机位、先采无人背景。真实现场的识别率和阴影抑制效果尚待验证。

## 使用与现场对比

1. 下载本轮 checked.bit，发送 `V`，确认回复 `L`；此前上半身版回复 `U`。
2. 发送 `C` 确认实时画面；冻结 F 最后回复 0，测试图 Z 最后回复 0。
3. 镜头固定，拍颈部以下至腰部附近并保留双臂、双手。人在画面外，待曝光稳定后发送小写 `b`，等待 `Q` 回复 `1`。
4. 进入画面，单独发 `U` 循环到编号 1，或直接发 `U1`，看原始前景。
   期望人体保留，白布/墙上的中等灰影减少；U3 看选中掩膜，U6 看 ROI 内 Canny。
5. 光照处理默认开启。发送 `~` 收到 `0` 为关闭，下一次 `~` 收到 `1` 为开启。
   在同一场景比较开启/关闭的人体和影子，不需要因开关切换重新拍背景。
   开关在帧边界生效并清除旧人体/匹配结果；等待几次快照重新确认。
6. 选定效果较好的状态，再观察每 0.5 秒自动输出的 POSE；`#` 仍可主动查询。
7. 相机移动、背景布置改变或照明条件明显改变时，无人重新 `b`。

N 仍设置前景差异阈值，默认 24，弱阈值 12；H/L/R 只控制 Canny，默认 0/0。
先用默认参数进行 `~` 对照，再判断是否需要调整 N；无需同时更改多个阈值。

## 为什么不用仅亮度差分

此前每个 2×2 Bayer 小块平均后，仅计算 `abs(当前均值-背景均值)`。
影子会造成明显变暗，因此可能成为前景；颜色变化但均值不变的衣服/物体也可能被漏掉。

新增处理直接保留同一坐标的四个 Bayer 样本（含两个独立绿色位置），
借鉴 [Horprasert 等的亮度/色度分离思路](https://vast.uccs.edu/~tboult/frame/Horprasert/)，
使用适合 FPGA 的固定点简化实现。参考 [OpenCV 的阴影判定说明](https://docs.opencv.org/4.12.0/d7/d7b/classcv_1_1BackgroundSubtractorMOG2.html)，
颜色近似不变的适度变暗可作为阴影线索；本实现独立使用以下固定规则，并未移植完整 MOG2。

## 算法与资源设计

### 全局曝光估计

- 在画面外侧各 1/8 的边缘带内，每 32×32 Bayer 小块抽样一次，减少画面中央人体对曝光估计的干扰。
- 只采集当前/背景颜色相近、未接近黑场或过曝的有效样本。
- 计算亮度比例 `round(32*当前均值/背景均值)`，在 16～48（0.5～1.5 倍）的 33 个桶中投票。
- 至少四个有效样本，且最高票占有效样本至少 1/4 时才更新。
- 在垂直消隐期将估计结果用于下一帧；突发变化允许一帧估计延迟。
- 分母为零、比例范围外的样本不参与投票；重新采集背景使模型恢复 1.0。
- 仅稀疏样本共用一个逐位除法器，不对每个视频像素做除法，不保存多帧 RGB。

### 颜色差异与阴影判断

设四个当前颜色样本为 `Ci`，背景为 `Bi`，总和为 `Sc`、`Sb`，整体增益为 `g/32`。

1. 用 `clamp(round(Bi*g/32))` 得到曝光补偿后的背景颜色。
2. 使用四个对应位置差异的最大值做前景差异，保留亮度相同但颜色不同的前景。
3. 通过四组交叉乘积比较颜色比例，避免逐像素归一化除法：
   `abs(Ci*Sb-Bi*Sc) <= floor(Sc*Sb/64) + 3*Sb`。
4. 仅当颜色比例接近、四通道未接近黑场/饱和，且当前均值处于补偿后背景均值的 62.5% 至 100% 之间，才将其视作阴影候选。
5. 同时从强、弱掩膜去除该候选，防止 R 的弱区域生长把影子重新连接到人体。

关闭 `~` 时恢复原来的均值绝对差分判据，保留相同视频输出时序。
仅 image3 打开此硬件；其他镜像默认编译参数关闭，原 UART 命令行为保持。
`src/vision/background_mask_pipeline.v` 中的 `background_gain_estimator` 与 `background_lighting_filter` 实现上述处理。
不新增完整帧缓存；Canny、上半身模板、三快照确认与周期 UART 输出继续保留。

## 可改善的范围与限制

目标是固定背景下的中等灰影、共同亮度变化，以及原亮度差分难以发现的颜色差异。
深色人体相对亮背景的强差异仍保留。过曝、过暗区域不用于可靠阴影判断。

这不是语义人体分割：灰色衣服与灰影可能同时满足颜色、亮度比例条件，导致人体被误删；
很深或明显带颜色的影子也可能保留。画面边缘大部分被人/影子挡住时，整体增益估计仍可能偏差。
颜色随时间大幅变化的光源、动态背景和摄像头移动超出本版验证范围。
单靠这些图像信息不能保证完全消除影子，同时绝不删除颜色相近的人体。
现场应通过 `~`、U1 和 U3 对照；若误删手臂，可先关闭抑制并反馈场景，而不是将仿真通过当成实拍成功。
