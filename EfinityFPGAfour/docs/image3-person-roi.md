# image3 固定背景与人体候选 ROI

本页记录单 RAW 阶段。当前保留 RAW 并增加串口 X 选择 E 边缘入口，
新命令、两种背景与 U 视图差异见 [RAW/E 双入口](image3-dual-input.md)。

本轮在 `images/image3_pose/image3_top.v` 启用 `PERSON_BUILD=1`。
处理对象是固定相机、相对稳定背景中的单个主要前景目标。输出是人体候选掩膜、
候选 ROI 和掩膜边界；不等同于人体语义分割，也没有姿势编号或真实关节输出。

修改前版本为本地提交 `a0aa82d`。本轮 GitHub 推送两次失败后，用户明确授权
按本地备份继续；没有把该提交声明为已完成远端备份。

## 上板操作

先 JTAG 下载本轮通过检查的 image3 文件（最终验证记录见文末），UART 115200/8N1。
本轮不自动下载 JTAG 或烧写 Flash。

1. 发 `C` 检查原始彩色画面，固定相机，让人离开画面。
2. 发小写 `b` 采集独立 RAW 背景，立即回复 `K` 只表示请求被接受。
3. 发 `Q` 查看背景状态：`B`=采集中、`0`=没有有效背景、`1`=背景已就绪、`!`=发生错误。
   `Q=1` 不表示已经识别到人体。忙时再次发 `b` 返回 `!`。
4. 发一个 `U` 查看原始二值差分，再发 `U` 查看整理后的全部前景。
5. 第三次 `U` 查看选中的候选掩膜，第四次查看候选边界，第五次查看候选掩膜与绿色 ROI。
   第六次返回原来的显示模式。这里是重复发送单字节 `U`，不是输入 `U5`。
6. 发 `N24`、`N32` 或 `N40` 加回车调整差分阈值；范围 0..255，返回 `K`。
   阈值越大越容易漏掉低对比度衣服。`H/L/+/-` 仍调 Canny，与 `N` 独立。
7. `D` 比较去噪方式：上电为 `2`（轻度去孤点），依次切换为 `0`（去噪旁路）、
   `1`（旧开运算）、`2`。三种模式后面都有短缺口闭运算，`0` 不代表整个形态学旁路。
8. `C/G/E/S/T` 返回普通画面；`E` 保留实际 Canny 边缘。`F` 仍控制显示冻结，
   `Z` 仍控制独立 HDMI 测试图。

RAW 背景采集与白平衡、Gamma 无关；传感器曝光变化仍可能影响差分。
背景不会自动更新，静止目标可以继续存在。相机位置改变后需要重新采集背景。
从普通画面切入/退出差分画面时，两个处理分支的同步相位不同，显示器可能有一次
重新同步；各稳定显示模式的有效画面仍为 1920×1080。

## 实际处理链

独立背景 DDR → 对齐当前 RAW → Bayer 2×2 平均 → 960×540 阈值掩膜 →
轻度去孤点/旧开运算/旁路 → 3×3 闭运算 → 2×2 OR 快照缩减至 480×270 →
精确 8 邻域连通域分析 → 主要候选选择与片段合并 → 选中片段的掩膜复制 →
边界提取 → 完整结果在显示帧开始发布。

- 背景使用 `0x01000000..0x013fffff` 独立 RAW 槽，不占 TF 相册缓冲。
  请求在完整摄像头帧边界开始，将下一帧写入背景槽；该帧不会被错误发布到实时环形缓存。
  显示保持上一张完整帧，后续摄像头帧恢复写入实时缓存。
- 实时与背景 DDR 读取交替仲裁，使用独立 FIFO，背景参考只在完整显示帧边界启用。
  无效样本、FIFO 断流、DDR 错误响应不会被当作零背景产生假前景。
- 轻度模式仅去掉 3×3 邻域内没有其他前景支持的孤立前景点；更有利于保留细手腕。
  闭运算只能修补局部小孔和短缺口，不重建大面积漏掉的身体。
- 快照的 OR 缩减尽量保留细小片段；最终候选掩膜与边界以每像素 4×4 的方式放大显示。
  ROI 是近似框，边界不是原始 1080p Canny 的逐像素人体外边缘。
- 精确连通域按真实前景像素数保留最大的 16 个片段。主候选默认最小 32 像素、4×8；
  与上一 ROI 重叠的候选获得位置连续性加分。与主候选相距不超过 8 个快照像素的
  片段按两轮有界扫描合并。附近杂物仍有可能被合并，远离的片段可以被排除。
- 再次从所选种子做连通遍历，仅复制这些片段的像素。没有将 ROI 内所有前景整体填白。
  片段间大空隙仍然保留；掩膜边界包括保留的孔洞边界，不只是一条外部封闭曲线。
- ROI 默认外扩 4 个快照像素（16 个显示像素）；向外立即扩张，向内每次发布最多收缩
  2 个快照像素。新位置明显不重叠时直接替换。没有目标的分析结果清除掩膜与旧框。
- 连通队列为 4096 项。队列溢出或输入失效时拒绝发布部分结果；超过 16 个片段时
  保留最大的 16 个，而不是无限增加标签 RAM。
- 原始/整理后差分按流输出；候选掩膜与边界是同一张完整快照的结果，采用双缓冲。
  分析繁忙时跳过输入帧，绝不暂停 HDMI。候选更新率随前景数量变化，不能称为 60 次/秒识别。
  不完整的结果不会在一帧中途替换显示。

新增模块 `background_mask_pipeline.v`、`person_snapshot_selector.v`、`person_roi_pipeline.v`。
共享控制器、UART 使用默认关闭的编译参数；image1/image2 不启用这些模块。
原图形识别、照片、Sobel 副本、彩色边缘着色和分屏仍不进入 image3。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/test-background-axi.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tools/test-person-roi.ps1 -FullSize
powershell -NoProfile -ExecutionPolicy Bypass -File tools/test-controls.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tools/test-canny-vision.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tools/test-sd4.ps1 -GalleryOnly
powershell -NoProfile -ExecutionPolicy Bypass -File tools/build-image.ps1 -Image 3
```

构建继续使用 TIMING_2/seed=6/effort=2，不放宽时钟约束。构建器核对编译前后应用 RTL
内容指纹、报告时间、实际保留的背景/候选模块以及全部列出的 Setup/Hold。
仅通过后才更新普通 `Ti60_Image3_Pose_checked.bit`；本轮另保留清晰命名的
`Ti60_Image3_PersonROI_checked.bit`，供此次下载辨别。旧 checked 文件不证明本次成功。

真实摄像头仍需验证无人误检、深浅衣服、静止站立、举手/张臂、阴影、边界和目标离开。
软件构造输入和综合时序通过，不代表已经获得实拍人体识别率。
