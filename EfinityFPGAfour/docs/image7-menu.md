# image7 HDMI 按键菜单

本版在用户已确认实时画面稳定的 image7 `video_guard_v2` 基础上加入菜单。
仅修改 image7 专用代码；image1、image5、image6 和原发布位流保留。
11 点 A 模型、MODEL7.BIN 内容、输入尺寸、96 MHz 推理时钟和 FT232H 数据包格式不变。

## 操作

- SW1（独立 KEY）：长按约 0.8 秒打开／关闭菜单；短按选择、切换开关、执行检查，或进入／确认数值编辑。
- SW2（ADC CH1）：浏览时向上；编辑时增加 1。
- SW3（ADC CH1）：浏览时向下；编辑时减少 1。
- CH0 旋钮：浏览时快速滚动；编辑时快速调值。关闭菜单时转动旋钮不改变参数。
- SW2+SW3 同时按下不执行菜单动作；原串口按键上报仍然保留。

菜单为左上角 540×288 像素英文文字窗口，一次显示 8 个项目；选中行黄色，编辑行青色。
使用 image1 的按键消抖、长按和字体思路，沿用 image5 的 ADC 接线与采样；不使用 OLED。
设置存在 FPGA 寄存器中，复位／重新下载后恢复原 image7 默认值，不写入 SD。

## 项目

1. `VIEW RGB`：短按循环 COLOR（RGB 彩色）→GRAY（灰度）→EDGE（Canny）→COLOR。
2. `INFERENCE`：允许／停止模型推理。ON 表示允许推理，BIN 检查通过后才实际运行；停止会让当前 DDR 操作结束并清除旧骨架；无有效模型时不能启动。
3. `SKELETON`：显示／隐藏 HDMI 的 11 点及连线。独立于推理和 FT232H 坐标输出。
4. `FREEZE`：现有 DDR 显示冻结功能。
5. `TEST RGB`：独立红绿蓝黄测试画面。菜单仍可操作，关闭该项恢复实时画面。
6. `CANNY H/L`：联动调整高阈值和半高阈值。
7. `CANNY H`：独立高阈值；降低到低阈值以下时同步限制低阈值。
8. `CANNY L`：独立低阈值，范围 0～当前高阈值。
9. `CANNY RESET`：恢复当前 image7 的高／低默认阈值 60／30。
10. `MEDIAN`：中值滤波开关。
11. `WB R`：红色白平衡增益，0～2047，Q8.8，256 为 1 倍。
12. `WB G`：绿色增益。
13. `WB B`：蓝色增益。
14. `WB RESET`：恢复 image7 原默认白平衡增益。
15. `GAMMA`：Gamma 开关。
16. `GAMMA P`：Gamma 强度，0～256。
17. `SD CHECK`：重新执行 SD→FAT32→模型文件加载和数值自检；本行 PASS 表示 SD 初始化及 FAT32 解析成功。
18. `BIN CHECK`：执行同一个完整检查流程；本行 PASS 还要求 MODEL7.BIN 已找到、文件头正确、CRC 正确、整网数值自检通过。

两项检查共用原生 SD 只读重载流程，避免独立扫描破坏当前权重。执行时自动停止新推理并等待在途推理和 DDR 事务排空，再重新读卡。显示 WAIT 表示正在等待／读取／自检；PASS 为当前真实里程碑；FAIL 显示对应 `Ehh` 十六进制错误码。检查成功后恢复检查前的推理开关，失败保持 OFF；检查期间再次选择 OFF 会取消自动恢复。

文件不存在时 SD CHECK 仍可 PASS（卡及 FAT32 可读），而 BIN CHECK 为 FAIL E04。这正好区分卡读通路与模型文件问题。文件必须是本工程配套 MODEL7.BIN；不能用 MODEL6.BIN 替代。

Canny、白平衡、Gamma 和中值滤波会影响送入模型的图像，调参后识别效果可能变化；比较原模型效果时先恢复默认。菜单不会自动修改训练权重。

## 串口与协议

原 115200、8N1 命令保留：C/G/E/T 切换显示，Z 测试画面，H/L、WR/WG/WB 等调图像参数，`~6+`／`~6-` 控制推理，`~6S/F/V/D` 读取状态。
菜单与串口共用图像配置寄存器，后到的写入生效；同一时钟拍冲突时菜单目标优先。菜单显示当前实际配置。
SD 检查期间启动推理请求不会中断检查；等完成后再操作。
实体按键 UART 上报与模型状态／二进制诊断整包互斥，避免按键消息插入诊断包中间。
FT232H 的 FT5! 图像包及 v2 kind=5 十一点坐标包均未改动。

## 时序收敛

加入菜单后的布局暴露了原卷积控制器中“分块行数 × 宽度 × 通道数 → 超出 RAM 容量”的长组合路径。该边界保护改成“分块行数 > floor(32768 / (宽度 × 通道数))”的固定层容量查表；地址、MAC、量化、层次调度和结果计算未改动，也没有放宽时钟约束。

`image7_tile_guard_tb` 检查容量表与当前层配置一致，并穷举 10 层 × 256 个分块位置，比较原判断与新判断。以后更换模型层宽度／通道数时必须同步更新 `pose7_conv.v` 的容量表；该测试会检查过期配置。完整网络和 SD／视频竞争集成测试也重新执行。

## 工程验证

- `tools/test-image7-menu.ps1`：GPIO 短／长按、导航／环绕／滚动、数值编辑和旋钮死区、SD/BIN 动作、UART/菜单配置共享、范围限制、三拍 RGB/同步延迟、菜单跨时钟握手。
- `tools/test-image7-standalone.ps1 -WithVideo`：真实 SD4/FAT32 卡模型、完整整数网络、在视频 DDR 竞争下的停止／重载、缺文件错误和恢复、CRC 和固定输入自检、USB 阻塞与报文。
- `tools/build-image7.ps1`：完整综合、布局布线、资源、各时钟 setup/hold、FT 引脚及原 MIPI 附加裕量门禁。

上述软件验证不能替代实板验收。下载后需确认长按可进入菜单、各键及旋钮有效、SD/BIN 显示 PASS、推理及骨架独立开关有效，并持续观察实时画面。
